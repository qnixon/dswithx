GnuCOBOL lets a paragraph `PERFORM` itself, but there are no local
variables: when we tried it, every level of the recursion saw the same
counter. So the tree grows from an explicit stack of node numbers. We pop a
node, print it, and push its right child before its left, which visits the
nodes in preorder. Instead of copying subsets, each training day records
the node it sits in, `WS-DAY-NODE`.

Thresholds come without a sort: `FIND-NEXT-VALUE` scans for the smallest
value above the current one, stepping through the distinct values in order.
COBOL has no decision tree to avoid. At 360 lines, the program is about
three and a half times the 106-line Python.
